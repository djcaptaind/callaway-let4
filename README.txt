CALLAWAY LET 3 — VERSION 2.0

UPLOAD TO GITHUB
1. Open the callaway-let3 repository.
2. Replace index.html and style.css with the new versions.
3. Open the images folder and replace hero-background.jpg.
4. Commit the changes.
5. Refresh the GitHub Pages site and then refresh Canvas.

CANVAS IFRAME
Use this code in the Canvas HTML editor:

<iframe
  src="https://djcaptaind.github.io/callaway-let3/"
  width="100%"
  height="2850"
  style="border:0; width:100%;"
  loading="lazy">
</iframe>

Start with a height of 2850. Adjust it after viewing the finished page inside Canvas.

WEEKLY CHANGES
Open index.html and search for "Mission Brief" or "Mission Schedule".
Edit the text, commit the change, and refresh Canvas.
